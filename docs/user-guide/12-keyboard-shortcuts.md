# Keyboard shortcuts

## Files and tabs

| Keys | Action |
|---|---|
| **Ctrl+N** | New file |
| **Ctrl+O** | Open file(s) |
| **Ctrl+S** | Save |
| **Ctrl+Shift+S** | Save as |
| **Ctrl+W** | Close tab |
| **Ctrl+Tab** / **Ctrl+Shift+Tab** | Next / previous tab |
| **Ctrl+,** | Settings |
| **F1** | Open this user guide in your web browser |

## Editing

| Keys | Action |
|---|---|
| **Ctrl+Z** | Undo |
| **Ctrl+Y** or **Ctrl+Shift+Z** | Redo |
| **Ctrl+F** | Search keys and values (in text mode: find in text) |
| **Shift+Alt+F** | Format the whole file |
| **Ctrl+Shift+T** | Switch between Tree and Text |

## In the tree

| Keys | Action |
|---|---|
| **↑** / **↓** | Select the previous / next line |
| **→** | Open a group or list; if it's open, go to its first entry |
| **←** | Close a group or list; if it's closed, go to the group it belongs to |
| **Enter** | Edit the selected value in place |
| **F2** | Rename the selected setting |
| **Delete** | Delete the selected setting or item |
| **Ctrl+D** | Duplicate |
| **Alt+↑** / **Alt+↓** | Move up / down |
| **Shift+F10** or the **Menu** key | Open the right-click menu |

## While editing a value

| Keys | Action |
|---|---|
| **Enter** | Save (number boxes, key names, in-tree editing) |
| **Ctrl+Enter** | Save (multi-line text box) |
| **Escape** | Cancel |

## In table view

| Keys | Action |
|---|---|
| **Arrow keys**, **Tab** | Move between cells |
| **Enter** or **F2** | Edit the selected cell |
| **Space** | Toggle a true/false cell |
| **Delete** | Remove the setting from that row |
| **Escape** | Cancel editing |

## In text mode

| Keys | Action |
|---|---|
| **Ctrl+F** / **Ctrl+H** | Find / replace |
| **Ctrl+Space** | Suggestions |
| **Shift+Alt+F** | Format the text |
| **Alt+↑** / **Alt+↓** | Move line up / down |
| **Ctrl+/** | Toggle a comment (files that allow comments) |
