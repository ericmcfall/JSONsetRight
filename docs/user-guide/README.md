# SafeJSON User Guide

SafeJSON is a Windows app for creating and editing JSON files, such as the settings files used by
programs and websites, without having to type JSON yourself. You change values with ordinary
controls: text boxes, number boxes, checkboxes and lists. SafeJSON writes the JSON for you, so
you can't introduce mistakes like a missing comma, an unclosed quote or a mismatched bracket.

This guide is for people who use SafeJSON. You don't need to know how to program, and you don't
need to know JSON in detail. Where a JSON term matters, the guide explains it.

**Version:** this guide describes SafeJSON 3.0.

## How to read this guide

- **New to SafeJSON?** Read [Installing](01-installing.md) and the [Quick start](02-quick-start.md).
  That's enough to get going.
- **Looking for something specific?** Use the contents above, or the
  [Keyboard shortcuts](12-keyboard-shortcuts.md) and [Troubleshooting](13-troubleshooting.md) pages.
- Names of buttons and menu items are shown in **bold**, for example **Save as…**.
- Keyboard shortcuts are written like **Ctrl+S**: hold Ctrl and press S.

This guide is also available as a single web page, `SafeJSON-User-Guide.html`, which you can open
in any browser or print.
